Poisson Process (Shot Noise)

Each sample records whether at least one event occurs in a unit sampling interval. At rate λ, the probability that a sample is occupied is 1 - exp(-λ). Disjoint intervals are independent. An occupied sample has the specified amplitude, even if more than one event occurs in its interval; this output represents occupancy rather than event counts.
