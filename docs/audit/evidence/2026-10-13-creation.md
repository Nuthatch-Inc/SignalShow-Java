## Aperture × seeded noise → Threshold

- Create centered 256×256 real/imaginary function through the Aperture family,
  Cylinder. Set amplitude 2, X-Center 24, Y-Center -16, Radius 40. Open Plot,
  save complex samples, return to Edit.
- Create another through Noise; choose Uniform Noise, mean 0.5, Half-Width 0.5,
  Seed 7. Name it Noise. Plot, save, return to Edit and save again.
- In a mathematical system multiply Cylinder by Noise using the input picker.
  Save; search for Minus, select it and save Cylinder - Noise. Enter unmatched
  search text: the binary list becomes empty. Clear: all six choices return.
  Restore Times, then create a second system applying Threshold 1 to the product.
- Edit the original Cylinder radius from 40 to 32. Save the edited source,
  linked product and linked threshold, without recreating either system.

Both Cylinder arrays match an independent disk equation at every pixel. Raster
rows run downward while the aperture Y coordinate runs upward; the independent
oracle uses that coordinate convention. Seeded noise is identical across
Plot/Edit, finite and within [0,1), with observed mean 0.50130 and variance 0.08336.
This is bounded range/repeatability evidence, not distribution certification.
All product, subtraction and threshold samples match the saved sources exactly.
Threshold nonzero count changes from 2,540 to 1,616 with the radius edit.

## Polar Gaussian × angular Cosine → Absolute Value → Threshold

- Create another centered 256×256 function through the polar family. Set the
  radial part to Gaussian with center 48 and width 20; amplitude 1, exponent 2.
  Set the angular part to Cosine, period 90 degrees and phase 45 degrees.
- Name it Polar; inspect Plot, save and return to Edit. Create a linked Absolute
  Value system and a second system applying Threshold 0.5 to that result.
- Return to the original polar editor. Confirm the radial settings persisted,
  change the radial center to 60, and save the source and both linked results.

The ring and angular lobes render, both signs occur, all samples are finite,
and imaginary samples stay zero. Absolute Value and Threshold match independent
comparisons of every source pixel, both before and after the radial edit.
Threshold nonzero count changes from 3,060 to 3,816. This checks editing,
composition and propagation, not a new exact oracle for polar sampling.
