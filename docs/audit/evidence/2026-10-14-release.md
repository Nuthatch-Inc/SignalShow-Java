## CI fixture correction

The first release run, 38627551923 at source fe286a04c18ff49828abfca3cc4898706c04299b,
passed the Windows installer job but failed one Mac noise-edit regression.
GUIEventBroadcaster stores weak references; the test registered an otherwise
unowned capturing lambda that could be collected before source invalidation.
The ordinary seed value updated while the fixture retained cached old samples.

Adding a temporary System.gc() immediately before each of the two seed edits
reproduced 28 of 28 image-case failures. Retaining the callback through an explicit
finally-block unregister made all 37 noise tests pass with the same forced-GC
probe. The probe was then removed. No production code or numerical assertions
changed; other test listener registrations already retained their owners.
See release-ci-before, release-noise-gc-before and release-noise-gc-after logs.
The clean full package passes all 1,130 tests after removing the diagnostic probe.
The failed unpublished tag is rebuilt from the fixture correction.
