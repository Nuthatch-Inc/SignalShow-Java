# Native image and numeric exports — October 13, 2026

Continuous Audit, ordinary 2D files. macOS arm64, JDK 25, JAI 1.1.3. No new UI
controls or text. Two failures reproduced through File → Export Function as Data
or Image and then through production writer tests.

## BUG-025: numeric export appends the extension twice

CSV and text exports from an ordinary complex image create `.csv.csv` and
`.txt.txt` names. The dialog already adds the selected extension. ImageWriter
then asks Utils for the extension without its leading dot, but its format
lookup recognizes only dotted suffixes and appends the extension again.

The shared format lookup now accepts both chooser and filename suffixes and
uses locale-independent case conversion. CSV/text writes retain the dialog's
filename. Other format-lookup callers use the corrected method too.

## BUG-026: negative complex channels use the wrong shared display scale

Create real Constant −2 and imaginary Constant −1; select both channels for
PNG export. Shared bounds should be [−2,−1], yielding real byte 0 and imaginary
byte 255. Before the fix, the imaginary export is uniformly 127. The maximum
accumulator starts at Double.MIN_VALUE, a positive number, so negative samples
never replace it. Initialize the bounds to positive/negative infinity.

Four rectangular production cases export positive and negative complex channels
to PNG/TIFF and decode exact expected bytes. Two additional cases verify actual
CSV/text filenames, dimensions and every real/imaginary sample. A format round
trip checks chooser suffixes and Utils suffixes. **Seven focused tests: five
fail before, all pass after. Full package: 491 tests, zero failures/errors/skips.**
