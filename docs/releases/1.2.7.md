# SignalShow 1.2.7

This maintenance release fixes incorrect calculations, image import and display
problems found while testing ordinary signal and image workflows.

## Changes

- Correct the imaginary result of complex division at shared zero crossings.
- Preserve unit-magnitude complex values when raising them to large integer powers;
  examples such as `(-1)^256` no longer incorrectly become zero.
- Give negative-only images the correct contrast and histogram range.
- Evaluate imported radial/angular profiles at their actual coordinates and align
  the polar preview with the creation editor.
- Preserve sampled-profile scaling mode and source labels when duplicating a
  signal or image.
- Preserve signed and fractional grayscale TIFF samples when importing images.
- Align profile-cut markers with the selected pixels on wide corner-origin images.
- Keep image cursor readings synchronized with the current channel, display
  options and source; avoid an indexing error after increasing image size.
- Preserve corner-origin coordinates when preparing Phase Detour holograms.
- Restore a function's Histogram correctly after switching between documents.
- Associate existing field labels with editable controls and expose parameter
  names to accessibility tools.

## Verification and remaining limits

The release builds run the 1,256-test automated suite on macOS and Windows and
inspect the extracted contents of both finished installers. Application payloads
contain the current executable JAR, launcher configuration and JDK package
metadata. Old builds, tests, test reports and diagnostic launchers are excluded.

The latest native Mac check covers Gaussian/Rectangle creation, Threshold/Real
chains, parameter edits, reopening the chain editor, saving and reloading samples.
Nineteen keyboard/paste entries and four independently verified exports passed.
Broader native checks for the new fixes and Windows interactive acceptance remain
separate follow-up work.

Mac keyboard entry works in a focused session, but a hidden/background Java window
can lose keyboard focus. Reliable recovery without restarting remains unresolved;
direct accessibility value setting is also unsupported on the tested controls.
Accessible field names do not establish full screen-reader support.

Complex-data saves preserve samples, dimensions, origin and name, not editable
generators or linked operation graphs. Binary image operations require matching
dimensions. Large images and transforms still use substantial memory. Numeric
parameter entry retains three-decimal precision. These are documented limitations,
not claims that every parameter or platform combination has been tested.
