# SignalShow 1.2.5

This maintenance release improves ordinary signal and image creation, editing,
operation chains and saving. It preserves the existing Java application workflows.

## Changes

- Correct linked results after source/operation edits, duplicate edits and image
  resizing. Incompatible image dimensions no longer crash downstream previews.
- Fix rectangular image rotation, profiles, imports and reuse of saved/exported
  sampled images. Restore missing editors when opening populated images.
- Keep operation previews and parameter fields usable; correct arithmetic symbols
  in composed function equations.
- Fix complex powers losing phase, corner-origin polar coordinates, sampling and
  frequency demonstration results, and selected convolution/display defects.
- Release TIFF and BMP file handles after export so Windows can rename or delete
  saved images immediately.
- Preserve folders containing dots when saving, preventing files from being
  redirected to an unintended path.
- Improve complex-data save/reopen, image exports and cleanup of retired editors,
  previews and animation timers. Remove the obsolete fixed 2 GiB heap cap.

## Requirements and running

The portable `signalshow-1.2.5.jar` includes its JAI dependencies and requires
Java 25 or later. Run `java -jar signalshow-1.2.5.jar`, or double-click it where
executable JARs are associated with Java. This JAR can be transferred to Windows;
it is not a Windows installer and does not include a Java runtime.

Native Mac (Apple Silicon) and Windows (x64) installers bundle Java. Download the `.dmg` for Mac or
`.msi` for Windows. Windows usage testing remains scheduled for a later round.

## Verification and remaining limits

The Mac audit currently records 74 checked scenarios, two pending Windows scenarios
and two deferred memory checks. These include native ordinary 2D creation and
operation chains, source edits, duplication, views, save/reopen and resized
rectangular Fourier chains. Counts describe bounded checks, not whole-app or
whole-platform certification. The release builds pass all 612 automated regressions on both Mac and Windows.
Both finished installers were extracted and inspected: their application payload
contains only the current JAR, launcher configuration and JDK package metadata.
Old builds, test classes and reports are excluded. The packaged Mac app
creates and saves a Gaussian→Squared Magnitude workflow correctly. Further
packaging details are recorded separately in the dated release evidence.

Complex-data files save samples, dimensions, origin and name; they do not preserve
editable generators or linked operation graphs. Binary inputs need matching image
dimensions. Dense images and transforms still consume substantial memory. Parameter
entry retains its existing three-decimal precision. Saving over an existing file
replaces it directly. Minor Rectangle equation notation and occasional nonblocking
macOS Java help-image accessibility errors remain documented.

Further ordinary usage and mathematical testing will continue before adding
features toward Chirplet parity.
