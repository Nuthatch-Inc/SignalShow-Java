# SignalShow 1.2.6

This maintenance release fixes substantial calculation errors and ordinary image
creation and operation-chain problems found during the mathematical and usage audit.

## Changes

- Correct division precedence, parentheses and nested unary operations. Expressions
  such as `A+B/C`, `2+(3*4)*5` and `Real(Threshold(A))` now retain their intended
  grouping and both complex channels where applicable.
- Keep cleared and rebuilt operation chains connected to their library entries
  and downstream results, including after reopening the editor.
- Preserve rectangular image width, height and origin when creating the next
  image. Editing a 2D origin no longer changes the next 1D signal's origin.
- Correct vertical image reversal, polar Delta placement and rectangular/E aperture
  boundaries so ordinary images occupy the intended coordinates.
- Fix hologram encoding crashes at phase +pi, preserve its source data, and correct
  phase quantization and complex error diffusion.
- Correct the cepstrum transform direction for complex signals and images.
- Fix crashes after editing the Poisson noise seed, and correct Poisson Process
  event occupancy. Seeded Poisson Process patterns change with the correction.
- Preserve scaled sampled-signal geometry when moving it partially outside the
  view, and use the intended higher-resolution Bar Chart resources.

## Verification and remaining limits

The release pipeline runs the 1,130-test automated suite on macOS and Windows
and inspects the extracted contents of both finished installers. The application
payload contains only the current executable JAR, launcher configuration and JDK
package metadata; old builds, test classes and test reports are excluded.

Native Mac checks cover grouped image creation, Threshold/Real chains, parameter
edits, clearing/rebuilding/reopening chains, complex arithmetic and rectangular
image defaults. Twelve saved complex-data exports from the latest two batches
match independent numerical expectations. Windows interactive acceptance remains
scheduled for a later round; automated Windows tests are separate evidence.

Complex-data saves preserve samples, dimensions, origin and name, not editable
generators or linked operation graphs. Binary image operations require matching
dimensions. Dense images and transforms still use substantial memory. Parameter
entry retains three-decimal precision. Existing rotation conventions and other
bounded audit limitations are recorded in the repository's testing plan.

Further ordinary usage and mathematical testing will precede work toward Chirplet
feature parity. These checks cover specific workflows, not every parameter or
platform combination.
